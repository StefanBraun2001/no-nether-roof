# NNR - No Nether Roof

Server-side Fabric mod. Detects players standing on top of the Nether
(the "Nether roof", Y ≥ 128 by default) and teleports them back to their
bed/respawn-anchor spawn point - or the world spawn if they don't have
one - with a warning message.

Current build: **A0.1.0** (alpha), MC **26.2** only. Not yet on GitHub -
build from source with `./gradlew build` inside `26.2/`; the jar lands in
`26.2/build/libs/`.

## Install

Server-side only - install on the server. Needs Fabric Loader + **Fabric
API**. No client-side installation required; players can join without the
mod.

## How it works

Every server tick, each player in the Nether dimension is checked. If a
player's Y-coordinate is at or above the configured threshold, they're
teleported off the roof (using the same bed/anchor-or-world-spawn logic
vanilla respawn uses) and shown a chat message:
"Usage of the Nether Roof is not allowed on this server."

If a player's own bed/anchor spawn happens to also be on the roof, the
mod falls back to the world spawn instead of teleporting them right back
into the trigger zone.

## Config

Config file: `config/nnr.json` (created on first run).

- **enabled** (default: `true`) - master switch.
- **yThreshold** (default: `128`) - Y-coordinate at/above which a player
  is considered "on the roof".
- **ignoreSpectators** (default: `true`) - spectators are never affected.
- **ignoreCreativePlayers** (default: `true`) - creative-mode players are
  never affected.
- **ignoreOps** (default: `true`) - server operators are never affected,
  so ops can fly up to patch remnant Nether portals or other roof
  structures without being bounced back down.
- **whitelistedPlayers** (default: empty) - list of exact player names
  (case-insensitive) who are always exempt, regardless of the settings
  above, e.g. `["Stefan", "SomeFriend"]`.

Editing the file requires a server restart (or reload, if one is added
later) to take effect - there's no in-game config screen, since this mod
has no client-side component.
